# THE JUKEBOX

Каталог виниловых пластинок — статичный сайт, без сервера и базы данных, все данные лежат в `data.js`, обложки — в `covers/`.

## Как выложить на GitHub Pages (получить постоянную ссылку)

1. Откройте репозиторий на github.com → вкладка **Settings**.
2. В левом меню — **Pages**.
3. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**.
4. Branch: **main**, папка: **/ (root)** → **Save**.
5. Через 1–2 минуты GitHub покажет ссылку вида `https://sergio-online.github.io/vinyl_collection/` — она и есть постоянный адрес каталога, открывается в любом браузере на любом устройстве, включая телефон, без всяких QuickLook-ограничений.

## Структура

- `index.html` — вся вёрстка, стили и логика (поиск, сортировка, фильтры, карточка с подробностями, зум обложки).
- `data.js` — данные о пластинках.
- `covers/` — обложки (42 файла, JPEG).

## Обновление данных

Чтобы что-то поменять — правите `data.js` (или просите Клода сделать это и прислать обновлённые файлы), коммитите и пушите — GitHub Pages подхватит изменения автоматически за минуту-две.
